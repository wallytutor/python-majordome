# Package databases

## Calphad

- `sample/simple-calcination.lua`: Calcite, Lime, CO₂, Diaspore, H₂O, Al₂O₃

- `haas1981.lua`: Haas & Fisher (1981) data for oxides

- `hallstedt1990.lua`: CaO–Al₂O₃ stoichiometric phases (Hallstedt 1990)

- `hallstedt1990.tdb`: Original CALPHAD TDB source (reference)

- `huang1995_sio2.lua`: SiO₂ solid polymorphs and liquid (Huang et al. 1995)

- `nasa.lua`: NASA gas-phase database (large)
